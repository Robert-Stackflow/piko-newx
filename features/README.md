# 媒体工具开发中

分支 `codex/media-tools`。目标仍为固定 X 12.22.0-prod.01 / Piko 3.10.6；不改已安装包。

用户范围：视频进度/倍速/长按加速/防误触、下载管理、本地帖子和视频浏览历史。视频历史必须包含视频页滑动后观看的后续视频，不能仅记录打开视频页的第一条，也不能记录预取。

用户已明确视频判定规则：视频成为前台当前页就记录，不设播放时长门槛，暂停或尚未开始播放也算。连续滑到下一条时逐条记录；预加载的相邻页不算，也不能重置当前页的去重状态。离开再返回同一视频更新最近访问时间。接入时必须监听页面选择，不能只依赖播放进度事件；锁屏、后台和未选中页面仍不记录。

当前已接入预览构建：观看判定、私有存储、下载任务界面及重试、原生事件桥接、续播和防误触。由配置 `media_tools_preview` 显式开启，不进入稳定分支。最终 DEX/ART 和真机验证完成前，不声称功能已交付。原生倍速记忆与长按加速复用现有实现；续播增加独立本机记录。证据与验收见 `EVIDENCE.md`。

历史默认关闭；只保存在 app 的 no-backup 私有目录，不接入设置导出，不采集私信、令牌或网络请求。关闭开关停止记录；清空操作需要阻止旧的排队写入恢复已删除记录。容量和保留时间有界。预加载/非活动页面/锁屏不应产生观看记录。

本目录与 `fixes/` 的七文件原有功能清单分开维护，未验证模块不通过放宽原有清单混入安装包。
